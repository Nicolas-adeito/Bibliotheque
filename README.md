Objectif  : 
Mettre en pratique les différentes étapes du cycle de développement logiciel (SDLC) en utilisant des outils libres de conception, de gestion de projet, de modélisation et de développement.
Contexte
La bibliothèque universitaire souhaite informatiser la réservation des salles de lecture.
Les étudiants doivent concevoir un système permettant :
●	l'inscription des utilisateurs ;
●	la réservation d'une salle ;
●	l'annulation d'une réservation ;
●	la consultation des disponibilités ;
●	la génération de statistiques simples.
